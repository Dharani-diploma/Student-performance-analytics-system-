# Student Performance Analytics System

**Student:** Ediga Dharani  
**Branch:** B.Tech – Artificial Intelligence and Machine Learning (AIML)

## Objective
Analyze student marks and attendance using Python, NumPy, and Pandas, and summarize the results.

## Technologies Used
- Python
- NumPy
- Pandas

## Dataset Description
`students.csv` contains 20 fictional student records with the columns `Student_ID`, `Name`, `Maths`, `Python`, `DBMS`, and `Attendance`.

## Implementation
1. Load the CSV file with Pandas.
2. Validate that the expected columns are present.
3. Calculate each student's average across Maths, Python, and DBMS using NumPy/Pandas.
4. Calculate average marks for each subject and average attendance.
5. Save the analyzed data to `student_analysis_output.csv`.

## Key Features
- CSV data loading and column validation.
- Student-wise average marks calculation.
- Subject-wise average marks and average attendance summary.
- Export of analyzed records to a CSV file.

## How to Run
1. Install Python 3.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python main.py`

## Output
The program prints a summary in the terminal and creates `student_analysis_output.csv` when run.

## Final Outcome
The project demonstrates a basic student-data analysis workflow using Python, NumPy, and Pandas.

## Challenges & Learning
This project practices reading CSV data, checking columns, using DataFrames and numerical operations, running a Python program, and exporting analysis results.
